## 4.0 — 2026-11-11 02:32 PST

Earlier versions grew out of a skill written at a former employer, so this one was rewritten from scratch by an agent that never saw any earlier version, working only from a plain description of what the skill must do (rather than editing 3.0, because edited text keeps its origins).
- Shares no wording with the former employer's copies apart from standard Keep a Changelog link lines and code; an independent comparison rated it clean.
- Tested blind on 12 invented scenarios against 3.0, the former employer's version and no skill: 4.75 out of 5, against 4.29, 4.04 and 4.06. Replies are about 35% shorter.
- New entry layout leads with the reason and ends with who asked. Rebuilt history goes in one marked block with no made-up version numbers. Updating the maintenance section logs a "Version unchanged" entry. The check script is now `scripts/check_skills.py`.
- Known gaps: converting an old history whose entries have no versions isn't fully covered; sometimes returns only the changed part of a file.
