# Changelog

History of changes to this skill, newest first. See the maintenance note in SKILL.md for how to keep this file current.

## v1.0 — 2026-11-11 11:15 PT

Initial build of a skill that keeps a build log of lessons from any project or conversation, in a Claude Doc, so they can become posts, talks and portfolio pieces later. Directed by Ben Shapiro.

Decision: capture every candidate straight into the log's Inbox. Options: offer candidates in the chat reply first. Reason: in Tycho, lessons offered only in chat were the main way lessons got lost.

- Added Capture (during the work, with a duplicate check that deepens an existing row instead of adding one) and Curate (keep, merge or cut; frameworks; a rebuilt summary), because Tycho's hand-typed counts drifted out of date.
- Added Kind (Lesson or Framework) and Source columns, because the owner kept asking for frameworks to be moved in and for where a lesson came from.
- Added one writer per log, with themes that come from each log's own lessons. Built from Tycho's build log, 29 Oct to 11 Nov 2026.
